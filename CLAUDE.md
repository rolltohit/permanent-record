# Rec Room

Private, invite-only music recommendation app for a group of friends.
Next.js 16 (App Router) + Supabase (Postgres, email-code auth, RLS) + Tailwind v4.

- Schema and all access rules: `supabase/migrations/`. RLS is the source of
  truth for permissions; server actions (`src/app/actions.ts`) run as the user.
- Music lookup: `src/lib/music/` (iTunes Search + Spotify page tags + YouTube oEmbed,
  no keys; song.link/Odesli only when `ODESLI_API_KEY` is set, as its free API closed).
- Sign-in is an emailed code plus a one-tap link (`/auth/confirm`, token hash,
  works on any device); joining is `finishSignIn` in `src/lib/auth-server.ts`.
  The email template is `supabase/templates/sign-in.html`.
- AI content is never generated by the app. It comes from the local batch:
  `npm run ai:pull` → Claude writes JSON (skill: `.claude/skills/refresh`) →
  `npm run ai:push`. Shared contract: `src/lib/ai/batch-schema.ts`.
- `.ai-work/` holds the group's data: never commit it.

Checks: `npm run lint`, `npm run typecheck`, `npm test`,
`npm run test:rls` (local Supabase), `npm run test:e2e` (local Supabase + seed).
